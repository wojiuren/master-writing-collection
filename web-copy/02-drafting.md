# 02 写作中

## 开头与入场

```text
请检查我的小说开头是否有效。先诊断，不要直接重写全文。

开头正文：
{正文}

目标类型和读者：
{题材与目标读者}

请输出：
1. 开头给出的读者承诺是什么
2. 第一处真正的变化、压力或异常在哪里
3. 哪些信息可以延后
4. 钩子是否和后文类型承诺一致
5. 哪些句子、对话或视角问题可能是全稿病灶
6. 给出 3 种更强的开头入场方案
```

## 场景写作

```text
请诊断这个小说场景。先不要重写，先判断它是否有效。

正文：
{正文}

请输出：
1. 这个场景的一句话任务
2. 人物进入场景时想要什么
3. 阻碍是什么
4. 场景中发生了什么变化
5. 哪些内容只是进门、寒暄、路程、重复布景或已知说明
6. 最晚可以从哪里开始，最早可以在哪里结束
7. 场面调度如何服务关系和信息
8. 结尾能否用新问题、新发现、新危险、新决定或关系变化剪切推进
9. 三条修改建议，按优先级排序
```

## 情节推进

```text
我正在写小说，现在卡在情节推进。请先诊断，再给推进方案。

当前剧情：
{已有剧情}

人物关系：
{人物关系}

限制：
{限制}

请输出：
1. 当前情节卡住的原因：目标不清、阻碍不强、后果不足、关系没变、信息没推进，还是中段没有升级
2. 主角此刻最具体的目标
3. 如果主角不行动，会失去什么
4. 5 种下一步推进方案
5. 每种方案包含：核心事件、主角行动、阻碍、结果、后果、结尾钩子
6. 哪一种最稳，哪一种最有爆点，哪一种风险最大
```

## 冲突悬念伏笔

```text
请帮我为当前剧情设计冲突、悬念和伏笔。不要为了反转而反转。

当前剧情：
{已有剧情}

已知秘密或真相：
{秘密或真相}

人物关系：
{人物关系}

请输出：
1. 当前最适合的冲突类型：目标、资源、权力、价值、关系、内心
2. 读者现在知道什么、不知道什么
3. 人物知道但读者不知道什么，读者知道但人物不知道什么
4. 一个短期悬念和一个长期悬念
5. 5 个伏笔：每个都说明第一次出现的当前功能和后期回收方式
6. 一个反转方案：说明为什么意外，以及为什么合理
7. 哪些设计会显得太刻意
```

## 人物关系与角色行动

```text
请帮我设计或诊断一场人物关系推进戏。目标是让人物通过行动、选择和潜台词改变关系。

人物 A：
{人物A}

人物 B：
{人物B}

当前关系：
{当前关系}

这一场之后关系要变成：
{目标变化}

剧情限制：
{限制}

请输出：
1. A 的目标、动机、恐惧和底线
2. B 的目标、动机、恐惧和底线
3. 两人的目标哪里重叠，哪里冲突
4. 场景中的外部任务
5. 三个关系变化节拍
6. 一个非语言动作或物件细节
7. 这场戏如何改变后续剧情
8. 如果角色行动不可信，指出原因并给替代行动
```

## 视角与叙述声音

```text
请帮我检查这段小说的视角和叙述声音。

正文：
{正文}

我想要的阅读感受：
{目标感受}

请输出：
1. 当前视角是谁，叙述距离近还是远
2. 哪些句子越界知道了不该知道的信息
3. 叙述声音是否符合人物身份和情绪
4. 哪些信息可以利用视角限制制造悬念
5. 如果改成更近/更远的视角，各有什么效果
6. 给出一小段示范改写
```

## 对话与潜台词

```text
请把下面这段对话改得更有潜台词。不要改变剧情事实，不要新增复杂设定。

原文：
{正文}

人物关系：
{人物关系}

目标：
{更暧昧 / 更紧张 / 更克制 / 更有火药味}

请输出：
1. 每个角色的明面话题和隐藏目标
2. 哪些台词是在替作者灌输信息
3. 修改后的对话
4. 哪些直白信息被改成动作、停顿、回避或暗示
5. 3 句可替换台词
```

## 节奏与连载推进

```text
请检查这一章的节奏和连载钩子。

正文或剧情摘要：
{正文}

目标读者：
{目标读者}

请输出：
1. 本章读者获得了什么：信息、情绪、关系、冲突、爽点、悬念
2. 哪些地方节奏慢，原因是什么
3. 哪些地方应该展开
4. 哪些说明可以改成行动或删掉
5. 当前结尾是否有继续阅读动力
6. 给出 3 个不同强度的结尾钩子
```

## 描写意象与氛围

```text
请帮我增强这段小说的描写和氛围，但不要堆砌辞藻。

原文：
{正文}

目标氛围：
{目标氛围}

请输出：
1. 这段描写应该服务人物情绪、场景压力、悬念、关系，还是世界规则
2. 原文缺少哪类可感细节
3. 可以使用的 3 个核心意象
4. 环境如何参与人物行动
5. 修改后的示范段落
6. 哪些描写应该避免，因为会显得过度
```
