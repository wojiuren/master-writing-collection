# 网页端直接复制区

这里是给 DeepSeek、Kimi、豆包、通义、ChatGPT 网页端用户准备的提示词区。

不需要安装 Skills。  
不需要接入 API。  
不需要理解本地工作流。  

你只要打开对应文件，复制提示词，把 `{变量}` 替换成自己的内容，然后粘贴到网页端模型里即可。

## 怎么选

- 不知道用哪个：先用 [00-router.md](00-router.md)
- 还没开始写：用 [01-prewriting.md](01-prewriting.md)
- 正在写章节或场景：用 [02-drafting.md](02-drafting.md)
- 已有草稿要修改：用 [03-revision.md](03-revision.md)

## 使用建议

- 一次只解决一个问题，不要把所有提示词都塞给模型。
- 正文尽量放在提示词最后，用分隔线包起来。
- 如果只是润色几句话，直接用 `轻量润色`，不要启动复杂诊断。
- 如果模型开始扩写世界观或新增人物，可以追加：`请不要新增设定，只处理我给出的文本。`
