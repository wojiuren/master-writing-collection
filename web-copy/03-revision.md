# 03 写作后

## 全稿体检

```text
请帮我做小说体检。先诊断，不要直接重写全文。

文本或摘要：
{正文或大纲}

我的目标：
{目标}

请输出：
1. 最有效的 3 个地方
2. 最影响阅读的 3 个问题
3. 开头承诺和结尾兑现是否一致
4. 主线因果是否清楚
5. 人物动机和变化是否可信
6. 节奏哪里拖、哪里跳
7. 修改优先级：必须改 / 可以改 / 暂时不管
```

## 结构级修订

```text
请帮我做结构修订建议，不要先润色句子。

故事梗概或章节列表：
{已有结构}

请输出：
1. 主线因果链是否完整
2. 开头承诺和结尾兑现是否一致
3. 哪些章节功能重复
4. 哪些转折缺少铺垫
5. 哪些人物行动缺少动机
6. 哪些信息应该提前或延后
7. 一个更清晰的章节顺序建议
8. 修改时最容易破坏的东西
```

## 人物线修订

```text
请检查人物线是否成立。

人物设定和剧情：
{人物与剧情}

请输出：
1. 人物起点是什么
2. 人物终点是什么
3. 中间缺少哪类压力、选择或代价
4. 哪些行动不符合人物动机
5. 反派是否有自己的胜利条件
6. 哪些配角没有发挥功能
7. 如何用 3 个场景补强人物线
```

## 场景级修订

```text
请帮我做场景级修订。先判断这场戏的问题，再给重写方向。

场景正文：
{正文}

请输出：
1. 这场戏目前承担什么功能
2. 这个功能是否值得保留
3. 应该删、合并、提前、延后还是重写
4. 场景冲突强不强
5. 信息量哪里过多或不足
6. 最晚进入点和最早退出点
7. 一个新的场景节拍表
8. 局部示范改写，不要重写全文
```

## 语言风格润色

```text
请轻量润色下面的中文小说片段。先判断是否真的是语言问题，再修改。

要求：
1. 不改变剧情事实
2. 不新增人物和设定
3. 保留原本叙述视角
4. 不把所有声音润成同一种漂亮文风
5. 优先处理病句、重复、拗口、节奏、说明腔

目标风格：
{目标风格}

原文：
{正文}

输出：
1. 问题判断：句子问题、信息问题、场景问题、视角问题分别有没有
2. 润色稿
3. 3 条以内关键改动说明
4. 如果发现不是语言问题而是结构或场景问题，请单独提醒
```

## 开头投稿与包装

```text
请从读者第一眼和投稿包装角度检查我的小说开头或简介。

开头或简介：
{正文}

类型和目标读者：
{题材与目标读者}

请输出：
1. 目前最清楚的卖点
2. 目前最模糊的地方
3. 简介是否包含主角、目标、阻碍和代价
4. 前几页是否兑现类型承诺
5. 哪些地方像外行信号
6. 三个可改进的简介版本
7. 开头最应该加强的一处
```

## 互评与反馈

```text
请用“三优三改”的方式反馈这段小说。

正文：
{正文}

作者目标：
{目标}

请输出：
1. 三个优点：每个优点说明为什么有效
2. 三个修改点：每个修改点给出具体位置、原因和改法
3. 一个最优先修改的问题
4. 一个不建议改动的地方
5. 如果你作为读者，最想继续看的点是什么
6. 哪些反馈只是读者感受，不一定要照单全收

语气要求：具体、直接、但不要打击作者。
```
