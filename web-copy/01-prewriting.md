# 01 写作前

## 灵感与素材

```text
你是中文小说灵感助手。请围绕我给出的素材，生成可写成小说的故事种子。

素材：
{素材、意象、梦、新闻、人物、设定}

目标风格：
{目标风格}

请先做两步：
1. 从五感、记忆、物件、关系、秘密、规则中扩展素材。
2. 再把素材转成故事种子。

请输出 8 个不同方向。每个方向包含：
1. 一句话梗概
2. 主角想要什么
3. 阻碍是什么
4. 如果失败会失去什么
5. 情绪吸引点
6. 一个潜在反转
7. 适合写成长篇、短篇还是章节桥段

不要写完整正文，只给可选择的故事种子。
```

## 作者状态与开工

```text
你是中文小说写作陪跑助手。请帮我把卡住的写作任务拆成今天可以开始的最小动作。

我现在卡住的原因：
{卡住原因}

我已有的内容：
{已有设定或正文}

请输出：
1. 我现在真正卡在哪一层：素材、结构、人物、场景、语言、情绪、完美主义
2. 今天只需要完成的最小任务
3. 一个 20 分钟写作步骤
4. 一个允许很烂的起手版本
5. 如果写坏了，后续怎么修
6. 今天不要做的事：列 3 条
```

## 人物初设

```text

题材：
{题材}

已有设定：
{已有设定}

1. 人物表层身份
```

## 结构与大纲

```text
请把我的小说点子整理成一个长篇粗纲。先不要写正文。

类型：
{题材}

目标读者：
{目标读者}

已有设定：
{已有设定}

请输出：
1. 这个故事的主契约：读者主要等待世界探索、谜题答案、人物变化，还是失衡事件解决
2. 开局：主角处境、诱发事件、读者钩子
3. 第一阶段：主角进入问题
4. 第二阶段：冲突升级和关系变化
5. 中点变化：人物策略或认知如何改变
6. 第三阶段：重大失败、揭示或转折
7. 第四阶段：反击、真相、结局兑现
8. 主线和副线分别是什么，在哪里碰撞
9. 每阶段 3 个可写章节节点
```

## 世界与背景

```text
请帮我整理世界观。目标是让设定服务人物行动和剧情冲突，而不是变成说明书。

世界观草稿：
{已有设定}

请输出：
1. 这个世界最核心的 3 条规则
2. 每条规则会给主角制造什么麻烦
3. 谁会从规则中获利，谁会受损
4. 规则会诱发什么利益冲突或社会关系
5. 哪些设定必须在开头出现
6. 哪些设定应该通过行动展示
7. 哪些设定可以删除或延后
8. 一个展示规则的具体场景
```
