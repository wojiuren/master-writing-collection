# 场景写作

## 适合

- 一场戏太平，读起来没有推进感。
- 不知道这一场该发生什么、功能是什么。
- 场景目标、冲突或信息量不清。
- 章节里有很多说明，但缺少行动和变化。

## 核心判断

场景是故事施工的基本单位。一个场景不是一段地点描写，而是在特定时间和地点发生的一组**戏剧动作、信息变化或情绪转折**。场景之所以存在，不是因为"故事发生在这里"，而是因为**人物的欲望遇到了障碍**，并且这个碰撞改变了什么。

每个场景都应是一个微型故事：某人想得到某物，遇到阻力，采取行动，得到临时结果。场景结束时局势通常应更糟、更复杂或更深入人物内心。

## 操作方法

### 1. 每个场景只抓一个主要任务

一个场景可以承担多种附带效果，但最好有一个主任务：

| 主任务类型 | 说明 | 例子 |
|-----------|------|------|
| 推进情节 | 发生一件事让故事朝新方向发展 | 主角发现关键证据被销毁 |
| 改变关系 | 两个人之间的位置发生变化 | A 请求 B 帮忙，B 有条件 |
| 揭示信息 | 读者或人物知道了一件之前不知道的事 | 原来死者和反派曾是合伙人 |
| 制造选择 | 人物必须在两个方向中选一个 | 救同伴还是继续追目标 |
| 展示人物 | 通过行动让读者理解人物 | 主角把最后一口水分给陌生人 |
| 改变情绪 | 气氛、紧张度或信任度发生变化 | 从怀疑到确信，从信任到动摇 |
| 增加风险 | 让代价变大、时间变少、选择变难 | 反派知道了主角的真实身份 |

如果一个场景同时塞进过多重大信息，读者会抓不住核心。一个场景最好只完成一到两个主任务。

### 2. 深切入，晚退出

进入点尽量靠近冲突、发现、选择或情绪变化。可以删除：
- 无功能的进门描写
- 寒暄和客套
- 路程和交通
- 重复布景（读者已经知道这个地方长什么样了）
- 已知信息的再次说明
- 人物独处时的大段内心独白

原则：再晚一步进入就会损害读者的理解——那就是合适的进入点。同样，一旦场景任务完成，尽快退出，不要拖到情绪和信息全解释干净。

### 3. 场景内部要有小型走势

一场戏可以像一个小故事：
- **开始**：人物带着目标进入
- **中段**：阻碍出现，信息或关系变复杂
- **末尾**：人物得到结果，但结果带来新问题

没有走势的场景通常只是资料说明或氛围片段。检查方法：如果这一场的内容可以压缩成两句话而读者不会错过任何变化，说明场景内部没有走势。

### 4. 用"行动→反应"链条驱动

人物行动后，环境、他人或内心应当产生反应。反应再推动下一步行动。

```
行动 → 反应 → 调整后的新行动 → 新反应 ……
```

这个链条一旦断裂（人物在行动后没有得到任何反应，或者反应不改变任何东西），场景就会停在说明里。

### 5. 场面调度服务关系和信息

地点、距离、物件、视线、动作都可以表达关系，而不仅仅是从视觉上描述场景：

- 谁靠近，谁后退——反映权力和舒适度
- 谁占据高处或出口——控制权
- 谁拿着关键物件——主动权
- 谁被迫沉默——被动或弱势
- 谁看见了别人没看见的东西——信息差

### 6. 结尾剪切推进

场景结尾不能停在"什么也没改变"的状态。最好停在以下位置之一：
- 新问题出现
- 新危险逼近
- 新发现改变判断
- 人物做出新决定
- 误解产生或揭示
- 情绪悬停未释放
- 关系位置发生变化

## 常见陷阱

- **无功能场景**：场景本身不推进情节、不改变关系、不揭示信息、不制造风险——但作者喜欢这个场景的氛围。删掉它。
- **信息倾倒**：人物站立不动，互相交换背景知识。这不是场景，这是百科。
- **进入太早，退出太晚**：场景已经完成了任务，但作者舍不得离开，继续让对话和描写多走了几页。
- **把场景当过渡**：人物从一个地方到另一个地方、从一件事到另一件事——如果过渡中没有冲突或信息变化，直接用"几个小时后"跳过。
- **场景堆砌**：十个进展缓慢的场景不如三个紧凑的场景。

## 快速诊断

- 这个场景的一句话任务是什么？
- 人物进入场景时想要什么？
- 阻碍他得到的东西是什么？
- 场景中发生了什么变化？
- 最晚可以从哪里进入？最早可以在哪里退出？
- 场面调度是否在表达关系或制造冲突？
- 结尾是否把读者推向下一场？
- 如果删掉这一场，故事会失去什么不可替代的东西？
- 这一场结束后，人物的处境比开场时更糟了吗？

```text
请诊断这个小说场景。先不要重写，先判断它是否有效。

正文：
{正文}

请输出：
1. 这个场景的一句话任务
2. 人物进入场景时想要什么
3. 阻碍是什么
4. 场景中发生了什么变化
5. 哪些内容只是进门、寒暄、路程、重复布景或已知说明

7. 场面调度如何服务关系和信息
8. 结尾能否用新问题、新发现、新危险、新决定或关系变化剪切推进
9. 三条修改建议，按优先级排序
```
