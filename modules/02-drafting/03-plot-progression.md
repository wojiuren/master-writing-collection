# 情节推进

## 适合

- 中段卡住，下一章不知道写什么。
- 事件很多，但读者感觉故事没有往前走。
- 转折太硬，节点之间缺少因果链条。
- 主线、副线、人物行动互相脱节。

## 核心判断

情节推进不是让更多事件排队发生，而是让**人物在压力下做选择，并让选择产生不可撤销的后果**。有效推进至少改变以下四件事中的一件：目标、风险、关系或信息。如果一章结束后这四个维度都没有变化，这一章很可能没有推进故事。

## 操作方法

### 1. 先找当前情节的发动机

在继续推进之前，先回答以下问题：
- 主角此刻最想要的一个具体目标是什么？
- 阻碍他的是人、规则、资源、误解、时间压力还是内心恐惧？
- 如果主角什么都不做，最具体的损失是什么？
- 主角下一步能主动做什么，而不是等待剧情推他？

如果主角在最近连续三场戏中都没有主动选择或行动，情节发动机可能已经熄火了。

### 2. 用"目标→阻碍→行动→结果→后果"检查每个节点

每个推进节点都应具备完整链条：

```
目标：人物想达成的即时结果
阻碍：谁或什么不让他达成
行动：人物采取的具体动作
结果：行动成功、失败、部分达成，还是付出代价
后果：这个结果如何影响下一步，而不是让故事归零
```

后果是推进的关键。如果结果没有产生不可逆的变化，情节会原地打转。

### 3. 中段推进不靠填充，靠升级

中段最常见的问题是人物在移动、解释、等待，但目标和代价没有变化。修复中段时考虑加入：
- 更具体的阶段目标
- 更强的反对力量（反派获得新资源或新信息）
- 一次行动成功后的反噬
- 一次失败后的新代价
- 一个迫使人物改变策略的信息
- 一个让关系变复杂的小选择
- 一个副线对主线的干扰

### 4. 转折要改变方向和选项

真正的情节转折不是"出现意外事件"，而是让人物原本的计划失效（或必须调整）。可用的转折类型：

| 类型 | 说明 | 例子 |
|------|------|------|
| 信息转折 | 人物或读者知道了一件改变判断的事 | 主角发现目标并不是真正的目标 |
| 关系转折 | 信任、权力、情感关系发生位移 | 盟友透露了关键信息但有所保留 |
| 目标转折 | 人物意识到自己追错了目标 | 复仇对象其实不是仇人 |
| 权力转折 | 资源、地位、人数、规则改变 | 反派获得了新的政治保护 |
| 道德转折 | 人物必须在两个都不好的选择中选一个 | 牺牲一个人救更多人 |

转折力度不在于"事件大小"，而在于它如何改变了人物的**可行选项**。

### 5. 主线和副线要互相加压

副线不应只是装饰。有效的副线功能：
- 暴露主角盲点：副线人物看到主角没看到的东西
- 制造时间或资源压力：副线事件占用主角本该用于主线的时间
- 改变人物关系：副线中的选择影响主线中的盟友或对手
- 提供主题对照：副线用不同方式呈现主线的主题问题
- 在主线低潮时制造反向推进：主线失败时副线成功（或反之），使节奏有起伏

### 6. 按功能标记所有场景

给当前所有场景标一个主功能标签：

```
建立 · 升级 · 揭示 · 误导 · 选择 · 损失 · 反击 · 兑现 · 余波
```

如果连续三个场景的功能相同（如都是"升级"），考虑合并或调整节奏。

## 常见陷阱

- **无因果的事件链**：事件A发生，然后事件B发生——但B不是A的结果。读者感觉"然后……然后……然后……"而不是"因此……因此……因此……"。
- **中段塌陷**：目标设定后，反派消失，主角被动等待，故事变成了日常流水账。
- **转折为转折而转折**：反转没有改变任何东西，只是短暂地制造了"哇"的效果。
- **人物不主动**：事件推着人物走，人物没有自己的选择。问题不在"慢"，在人物失去了行动权。
- **副线覆盖主线**：副线太有趣，主线被遗忘。读者想知道副线发生了什么，但主线已经停滞很久了。

## 快速诊断

- 主角最近三场戏有没有主动做出选择？
- 每个行动有没有不可忽略的后果？
- 中段是否只是换地点，没有升级压力？
- 最近的转折是否改变了人物的可行选项？
- 副线是否反过来影响了主线，还是平行推进互不干扰？
- 结尾是否在兑现开头做出的承诺？
- 如果删掉最近三章，故事连贯性会不会断？
