# 视角与叙述声音

## 适合

- 视角混乱，读者经常出戏。
- 不确定该用第一人称还是第三人称。
- 信息不知道怎么藏，悬念被提前破坏。
- 叙述声音不稳定，读起来像不同的人在写。

## 核心判断

视角决定读者能知道什么、误解什么、期待什么；叙述声音决定读者如何感受这个世界。视角和声音是读者进入故事的门——门不稳，人物、悬念和情绪都会变虚。

写作者在视角上的两个主要工作是：**决定读者通过谁的眼睛看世界**，和**决定读者和这个世界的距离有多远**。

## 操作方法

### 1. 先确定叙述位置

写任何段落之前，清楚三个问题：
- **谁在看**——当前段落的感知主体是谁？
- **谁在想**——内心活动属于谁？
- **谁在讲**——叙述者的声音来自谁？

### 2. 控制信息边界

当前视角人物不知道的事，叙述不要替他"知道"。这条规则适用于：
- 其他人的内心想法（除非视角人物能推测）
- 不在场的场景事件
- 未来的发展
- 他人隐藏的动机

要制造悬念时，优先利用视角限制，而不是强行隐藏全知叙述者知道的信息。视角人物自己也在"发现"和"误解"的过程中，读者会跟随他的认知过程。

### 3. 叙述声音来自观察方式

声音不是华丽句式或方言特色。声音是人物（或叙述者）如何**命名、判断、忽略和误读**世界。同一个场景，观察方式不同会导致完全不同的叙述：

- 一个冷静的人物会注意事实参数：大小、距离、人数、概率
- 一个愤怒的人物会注意冒犯和威胁：谁在挑衅、什么错了
- 一个天真的人物会注意新奇和感受：颜色、声音、第一次
- 一个疲惫的人物会注意需要回避的东西：更多麻烦、更多责任

### 4. 多视角切换要带来新价值

多视角不是把同一事件重复写几遍。每个新视角应当带来至少以下一项：
- 新的信息或对已知信息的不同理解
- 新的动机或对冲突的另一面解释
- 新的情绪角度或对事件的不同感受
- 新的悬念（读者知道一些事情会让下一章有压力）

### 5. 不可靠叙述要有线索

不可靠叙述不是随意撒谎。读者需要在回看时发现早有迹象：
- 视角人物的判断和事实有出入
- 叙述回避了某些话题
- 人物反复辩解或过度解释
- 其他人物对视角人物的描述有矛盾
- 视角人物的记忆和场景记录不一致

### 6. 展示与讲述不是二选一

展示（场景化呈现）和讲述（概括性叙述）各有用途：

| 场景内容 | 推荐方式 | 原因 |
|---------|---------|------|
| 关键情绪变化 | 展示 | 让读者亲历 |
| 过渡和压缩 | 讲述 | 避免拖慢节奏 |
| 人物第一次出场 | 展示 | 建立印象 |
| 已知背景回顾 | 讲述 | 快速更新认知 |
| 重要冲突 | 展示 | 制造紧张 |
| 长时段变化 | 讲述 | 控制篇幅 |

### 7. 一场一视角原则

在一个场景中，尽量避免切换视角。如果要换，应在章节或场景边界处切换，并在新场景开头尽快让读者知道"现在是谁在看"。

## 常见陷阱

- **视角越界**：在第三人称有限视角中，突然写了另一个人的内心活动。
- **声音不统一**：原本冷静的叙述者突然在描写中使用激烈的修辞。
- **为炫技换视角**：多视角切换只是为了展示"我可以写不同人"，而不是为了让读者获得新信息。
- **距离不稳**：一会儿离人物很近（细致感受），一会儿又很远（概述跳过多天），读者不知道在哪里定位。
- **信息不公平**：作者为了让悬念成立，刻意向读者隐藏视角人物已经知道的信息——这会破坏读者对叙述的信任。

## 快速诊断

- 当前段落是谁在看、谁在想、谁在讲？
- 有没有越界知道别人内心的句子？
- 叙述声音是否符合人物身份和当前情绪？
- 如果换一个视角人物来讲这段故事，会有什么不同？
- 哪些信息可以利用视角限制来制造悬念？
- 读者能否清晰说出叙述者和故事之间的距离？
- 多视角切换时，每次切换都带来了新价值吗？
