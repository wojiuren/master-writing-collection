# 作者状态与开工

## 适合

- 卡文、拖延、不敢开始。
- 写了开头就停下来了，觉得"还不够好"。
- 对题材、能力或读者反应过度焦虑。
- 想建立稳定写作习惯但不知道从哪里入手。

## 核心判断

开工阶段的最大敌人通常不是没有能力，而是**审查过早、目标过大、评价过急**。写作的状态和写作的能力是两件事。许多卡文不是写不出来，而是"写出来之后不满意"这个念头在生成阶段就开始工作了。生成阶段的任务是写出可修改的材料，修订阶段才有资格判断质量。把这两个阶段混在一起，是大多数卡文的根源。

## 操作方法

### 1. 把目标降级到"能开始"的程度

不要要求自己"写好一章"，这些目标更适合写好之后再回头评估：

- 写一个人物在压力下做的一个动作
- 写一段两个人的对话，其中至少有一人在隐瞒什么
- 写一个场景的进入点——不要开头，直接从中间切入
- 写十分钟自由写作，想到什么写什么，不检查、不回读
- 写一个"故意写得很烂"的版本

目标越小，开始的成本越低。

### 2. 暂时关闭内心审查官

写作时不做以下任何事：
- 不回读刚写的内容
- 不查资料
- 不调整措辞
- 不判断句子的好坏
- 不修改错别字和标点

审查官可以在修订阶段回来，但不能在写第一句话时就把作者按住。

### 3. 卡文先判断卡在哪一层

| 卡住的表象 | 可能原因 | 对策 |
|-----------|---------|------|
| 不知道写什么 | 素材不足 | 做灵感触发练习，找入口 |
| 知道写什么但不知道怎么排 | 结构不清 | 写目标、阻碍、结果三行式大纲 |
| 有人物但人物不动 | 欲望/恐惧不够具体 | 停下来写人物欲望和恐惧 |
| 有场景但写不动 | 任务不明或冲突不足 | 写场景目标和核心冲突 |
| 句子怎么写都不顺 | 语言层卡住 | 先写粗糙版，修订时再润色 |
| 盯着空白页发呆 | 情绪焦虑或疲劳 | 离开页面，休息，再写最小动作 |

卡在语言层时不要从素材层找解决办法，反之亦然。先正确归因。

### 4. 允许"写出来很烂"——刻意写坏

"坏稿"不是失败，而是暴露问题的工具。写一个"我知道很烂但我要先写出来"的版本，往往比完美主义空转更有效率。刻意写烂有时能恢复玩心，也能帮助作者更清楚地知道自己**不想要**什么。

### 5. 建立可重复的低成本开工仪式

固定这些要素能降低"开始"的心理成本：
- 固定的写作时间（不必很长，15-30分钟即可）
- 固定的写作时长（时间到了就可以停）
- 固定的写作地点（同一种环境信号）
- 固定的启动句子（每次都以"我今天要写的是……"开头）
- 固定的开工问题（如"人物此刻最想要什么？""这场戏的关键变化是什么？"）

目标不是营造神圣感，而是降低每次"开始"的决策成本。

### 6. 长期项目停摆后的恢复策略

如果已经停了几周或几个月：
1. 不要试图追回进度。进度是幻觉，质量才是真实目标。
2. 先恢复"每日接触"——不要求字数，只要求打开文档或笔记本。
3. 读一遍最后写的内容，不加评语。
4. 写一个"接下去可能发生什么"的清单，不用决定用哪个。
5. 写一小段最容易的内容——哪怕只是描述人物正在看什么。

## 常见陷阱

- **用准备替代写作**：查资料、做设定、排大纲、学习写作技巧……所有这些只有在"正在写"的前提下才有意义。准备不是写作。
- **等待灵感**：灵感常常在写作过程中出现，不是先兆。"写"才是触发灵感的行为。
- **用阅读替代写作**：读一百本写作书不如写完一个短篇再读一本。
- **不敢动已写好的内容**：草稿的唯一意义就是被修改。如果舍不得改，说明还没开始真正写作。
- **自我惩罚**：卡文时用"我就是不够自律""我没有才华"惩罚自己，会让下次开始更困难。

## 快速诊断

- 现在是"写不出来"还是"觉得写出来不够好"？
- 任务是不是太大了？
- 是不是在生产阶段使用了修订标准？
- 今天最小可完成动作是什么？
- 如果允许自己写一个最烂的版本，第一句话是什么？
- 如果这个问题持续很长时间，我是否需要帮助？有时候卡文是焦虑、抑郁或倦怠的信号，不只是写作问题。
