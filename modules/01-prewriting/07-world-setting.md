# 世界与背景

## 适合

- 世界观很多，但不知道怎么写进正文。
- 设定很酷，剧情却推不动。
- 想让规则制造冲突，而不是成为说明书。
- 奇幻、科幻或历史题材，背景知识需要有效曝光。

## 核心判断

世界观不是说明书，而是会**改变人物行动、资源、身份、风险和代价的规则系统**。一个有效的世界设定不是用来展示的——它应该让某些事情变得更容易，某些事情变得更困难，某些选择变得根本不可能。如果去掉世界设定故事还能照常发展，说明世界观还没有真正参与到叙事中。

## 操作方法

### 1. 先抓核心规则

从纷繁的设定中提炼三条最核心的规则。判断标准：如果删掉这条规则，故事会不会完全不同。

问三个问题：
- 这个世界和现实最关键的差异是什么？
- 这条差异给主角制造了什么具体的麻烦？
- 谁会从这条规则中获利，谁会受损？

### 2. 让设定变成人物必须面对的选择

一个有效的世界设定应该迫使人物改变行动：

| 无效设定 | 有效设定 |
|---------|---------|
| "这个世界魔法很普遍" | "每个人天生带有一种魔法，但使用它会缩短寿命"——人物必须选择是否使用 |
| "这是一个严格的等级社会" | "底层出身的人每升一级都必须举报一个朋友"——人物必须选择忠诚还是上升 |
| "这个世界被深海包围" | "深海里有怪物，但唯一能在经济上存活的出路就是出海"——人物被困在恐惧和需求之间 |

### 3. 通过场景展示规则，不要直接解释

错误的展示方式："这个世界有五个大陆，每个大陆由不同的元素守护……"

有效的展示方式：让人物因为世界规则受阻、占便宜、误解、冒险或付出代价。

**对比**：
- 说明："魔法师只能用左手施法。"
- 展示：一个魔法师在战斗中右手受伤，惊慌失措——不是因为疼，而是因为他不能施法了。读者自然理解规则及其代价。

### 4. 区分必需设定和可延后设定

开头只需要读者理解当前冲突。判断标准：如果读者不知道这条设定，能不能理解刚刚发生的事？

**必需立即给出的**：影响当前场景行动的规则，改变人物选择的社会关系，妨碍或帮助人物达成目标的障碍。

**可以延后的**：历史背景、完整谱系、术语体系、远程世界的规则、不直接相关的机构运作方式。

一个好用的检验方法：把介绍性段落全部删掉。如果读者还能通过人物行动自然理解世界规则，说明设定已经融入叙事。

### 5. 背景要参与氛围和关系

地点、阶层、职业、城市结构、气候、宗教、技术、法律、魔法——这些都影响人物之间的权力距离和情绪基调。

一个场景的天气不只是背景：它可以让追逐更困难、让重逢更压抑、让对话被迫缩短。一个社会的阶层不只是设定：它决定谁先说话、谁有权拒绝、谁会因为一句话陷入危险。

### 6. 用"差异"而非"体量"来建立世界感

很多世界观的问题是过于复杂（五千年历史，十五个国家，三十种魔法，四种语言）。读者记不住，也不需要记住。世界感来自**差异**而非体量：这个世界什么地方和读者熟悉的世界不同？这种差异如何影响日常生活中的微小选择？

一个建立在巨型真菌森林中的城市，比一个"有完整政治体系和三百万年历史的奇幻大陆"更让人印象深刻——因为它具体、可感、有差异。

## 常见陷阱

- **开头先上世界观教程**：读者还没关心人物，就开始学习世界历史。先让人物在行动中泄露规则。
- **所有设定一次性抛出**：需要读者记住太多新名词，造成认知过载。
- **设定不制造冲突**：世界观只是背景板，从来没有让任何事变得更困难或更复杂。
- **用宏大叙事替代人物故事**：世界正在毁灭、战争正在爆发、帝国正在崩塌——但如果没有人物的具体选择和代价，这些都只是新闻标题。
- **前后矛盾**：规则被打破是因为"剧情需要"，没有付出合理解释的代价。

## 快速诊断

- 这个世界最核心的 3 条规则是什么？
- 每条规则如何影响了主角的具体选择？
- 这些规则给主角制造了什么麻烦，给反派提供了什么优势？
- 哪些设定必须在第一章出现？哪些可以通过行动在后文展示？
- 如果删掉所有设定描述段，故事还能读通吗？
- 这个世界正在改变吗？变化是否制造了新的冲突和机遇？
