# 结构与大纲

## 适合

- 搭长篇粗纲，只知道开头和结尾，中段全是空白。
- 写到一半不知道下一章该往哪走。
- 故事散，事件很多但感觉没有推进。
- 短篇写好了但想扩展成长篇。

## 核心判断

结构不是套公式，而是**安排压力升级、信息揭示和人物变化**。大纲的价值不是限制灵感，而是让每个阶段知道自己要完成什么任务。结构的外部表现是事件顺序，内部动力是因果链——每一件事的发生都导致下一件事成为必要。

## 操作方法

### 1. 先确定故事的主契约

读者阅读的动力取决于他们主要等待什么。确定主契约有助于判断大纲重点应该放在哪：

- **等待世界探索**：读者想看到新规则、新地点和新秘密被不断揭示
- **等待谜题答案**：读者想知道"凶手是谁""真相是什么"
- **等待人物变化**：读者想看一个人如何被压力改变
- **等待失衡事件解决**：读者想看危机如何被解除

一个故事可以兼有多个，但必须有一个主导。如果主契约不清，大纲会缺乏焦点。

### 2. 四部分压力结构（适合长篇主线诊断）

不一定需要固定的页数比例，但功能应该清楚：

**第一部分：布局**
建立主人公、世界、初始处境。设置精巧悬念、伏笔和危机预感。任务是让读者进入故事并开始关心。

**第一转折点**：故事正式启动的位置。它完整呈现主要敌对力量或核心危机，改变主人公的计划。故事从这里变成"新游戏"。

**第二部分：反应**
主人公还没准备好主动解决问题。他在新局面中退缩、试探、逃避、误判、学习或被迫适应。不要让主角过早成熟——第二部分的功能就是让人物挣扎。

**中间点**：新的信息、认知、风险或策略让主人公从被动反应逐渐转向主动行动。这个转折是故事中段的灵魂。

**第三部分：进攻**
主人公开始主动追求解决方案，但仍受敌对力量、错误判断或心魔牵制。行动应带来升级——每次成功都产生新问题。

**第二转折点**：提供最后所需的信息或上下文切换。此后不应再塞入全新关键线索——结尾使用的东西应已被铺垫。

**第四部分：解决**
主人公用已获得的能力、信息和变化面对最终冲突。结局应该合情合理、有情感意义，完成外部冲突与内部弧线。

### 3. 大纲的最低要求

在写正文之前，至少知道以下几点：

- 开场：主角在什么地方，有什么欲望，有什么不满
- 触发事件：什么打破了日常，把主角推入新处境
- 重大选择：主角第一次必须做出不可逆决定的位置
- 中点变化：主角的策略、认知或目标在这里改变
- 最大失败：主角在接近目标前遭受的最重打击
- 最终对抗：主角如何用自己的方式解决问题
- 结局状态：故事结束后一切变成了什么样

### 4. 主副线的交叉点

副线不是平行跑道。如果副线独立于主线发展，会分散故事力量。给副线安排与主线发生碰撞的节点：副线的信息在某个时刻改变主线判断，副线的人物在主线的关键节点出手或背叛，副线的目标与主线的目标在某些事上冲突。

### 5. 场景清单按功能排序

在勾勒出结构后，列出每个场景的功能。功能可以是：

```
建立人物      升级冲突     揭示秘密
误导读者      制造选择     制造损失
反击对手      提供线索     情感回响
```

功能重复的场景可以考虑合并。如果某个场景回答不了"它在这里承担什么功能"这个问题，可能不需要存在。

### 6. MICE 框架判断故事重心

MICE 帮助判断不同类型的故事对结构的不同要求：

- **环境故事**（Milieu）：读者期待探索和奇观，结构重点在"进入→探索→离开"
- **思想故事**（Idea）：读者期待问题和答案，结构重点在"问题提出→调查→答案揭示"
- **人物故事**（Character）：读者期待身份变化，结构重点在"旧身份→变化压力→新身份"
- **事件故事**（Event）：读者期待秩序被打破和恢复，结构重点在"平衡→失衡→新平衡"

不同类型对"什么算有效事件"的定义不同。在环境故事中，一个新地点就是有效推进；在人物故事中，同样的地点转换如果没带来人物关系变化，就不算推进。

## 常见陷阱

- **开头太晚：第一部分五任务不清，悬念或危机太晚。
- **中段塌陷：第二部分只有逃跑或重复，没有中间点转换。
- **主角被动到底：第三部分没有从反应转为进攻。
- **结局机械：第二情节点之后还在补关键设定，或主角没有完成最后选择。
- **伏笔无效：线索没有绑定关键转折点。
- **大纲过度细化：写了五十页大纲才开始正文，写作中失去所有发现乐趣。

## 快速诊断

- 开头承诺的主问题是什么？
- 每一阶段是否让目标、风险、关系或信息发生变化？
- 中点是否改变了人物的策略或认知？
- 结尾是否处理了开头的承诺？
- 副线是否反向影响了主线，还是只是平行推进？
- 如果去掉所有副线和装饰，主线是否自洽？
- 这个结构是服务于这个故事，还是拿来套上去的？
